ทั้งหมด 0 ชุด

ยังไม่มีชุดข้อสอบ — กด “สร้างชุดใหม่” หรือ “นำเข้า CSV เป็นชุดใหม่” ได้เลย

รูปแบบไฟล์ CSV

หัวตาราง: ประเภท,คำถาม,ตัวเลือก1,ตัวเลือก2,ตัวเลือก3,ตัวเลือก4,เฉลย,คำอธิบาย,เวลา

• ประเภท = mc (4 ตัวเลือก) หรือ tf (ถูก/ผิด)
• เฉลย = เลขตัวเลือกที่ถูก (1–4) — ข้อ tf ใช้ 1=ตัวเลือกแรก, 2=ตัวเลือกที่สอง หรือพิมพ์ ถูก/ผิด ก็ได้
• ข้อ tf เว้นตัวเลือกว่างไว้ได้ ระบบจะใช้ข้อความที่ตั้งไว้ในแท็บ “แบรนด์ระบบ” — หรือกรอกตัวเลือก 1–2 เพื่อกำหนดข้อความเฉพาะข้อนั้น
• เวลา = วินาทีเฉพาะข้อนั้น (เว้นว่าง = ใช้เวลาของห้อง)
• บันทึกไฟล์เป็น CSV UTF-8 เสมอ (Excel: Save As → CSV UTF-8)

ระบบเกมตอบคำถามในชั้นเรียน

ข้อความปุ่ม ถูก/ผิด (True-False)

เช่น ตั้งเป็น “ประวิสรรชนีย์ / ไม่ประวิสรรชนีย์”, “ใช่ / ไม่ใช่”, “จริง / เท็จ” ได้ตามเนื้อหา

🎵 เพลงประกอบ

วาง direct link ของไฟล์เสียง (.mp3 / .m4a / .ogg) เช่นลิงก์จาก GitHub raw หรือเว็บโฮสต์ไฟล์เสียงที่เปิดตรงได้
⚠️ ลิงก์แชร์ของ Google Drive / YouTube ใช้ไม่ได้

เริ่มใช้งานใน 4 ขั้น

1) ไปแท็บ คลังข้อสอบ → กด ดาวน์โหลด CSV ต้นแบบ → พิมพ์ข้อสอบใน Excel/Google Sheets → บันทึกเป็น CSV UTF-8

2) กด นำเข้า CSV เป็นชุดใหม่ → ตั้งชื่อชุด เช่น “วิสรรชนีย์ ม.4” → ระบบบันทึกเก็บไว้ในคลังถาวร

3) แท็บ สร้างห้องเล่น → เลือกชุดข้อสอบ + จำนวนข้อ + เวลา → กดสร้างห้อง → ฉาย PIN/QR ขึ้นจอ

4) นักเรียนสแกน QR → ใส่ชื่อ เลือกตัวละคร → ครูกด เริ่มเกม

การให้คะแนน

ตอบถูกได้สูงสุด 1,000 คะแนน ลดหลั่นตามเวลาที่ใช้ (เร็วได้มากกว่า) + โบนัสตอบถูกติดต่อกัน (สตรีค) ข้อละ 100 คะแนน สูงสุด 5 สตรีค

แบรนด์ระบบ

แท็บ แบรนด์ระบบ เปลี่ยนชื่อระบบ/โลโก้/favicon ได้ทันที ค่าที่บันทึกจะถูกใช้กับทุกเครื่องที่เปิดเว็บนี้

ประหยัดโควตา Firestore

1 รอบเกม (60 คน × 15 ข้อ) ใช้ราว 2,000 writes / 5,000 reads อยู่ในโควตาฟรี (20,000 writes / 50,000 reads ต่อวัน) เล่นได้ราว 8–9 รอบต่อวัน
